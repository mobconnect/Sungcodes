# Sungcodes test checklist

## Functional

- [ ] Search finds an artist
- [ ] Search finds a file
- [ ] Clear search restores the library
- [ ] Featured cards open and viewer closes
- [ ] Preview, pause, resume and stop work without competing speech queues
- [ ] Copy and download provide success or failure feedback
- [ ] Draft save/load works
- [ ] Empty lyrics are rejected
- [ ] Genre and mood filters work independently
- [ ] Dark mode, larger text and reduced motion persist after reload
- [ ] Static library loads when GitHub is unavailable
- [ ] Offline fallback appears when cached files are unavailable
- [ ] Service worker updates after its cache version changes

## Browser and accessibility

Test Chrome, Firefox, Safari, Chrome Android and Safari iPhone; keyboard-only navigation; screen readers; offline mode; reduced motion; and high zoom.

## Content safeguards

Only publish original or authorised material. Report suspected infringement through GitHub Issues with the URL and evidence.
